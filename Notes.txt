In React : 
useState() has two components - variable , function to update the variable.
This is the only way you can update the variables in React.

Example to Illustrate

function Demo() {
  let plainVar = 0;                  // plain variable
  const [stateVar, setStateVar] = useState(0); // state variable

  return (
    <div>
      <p>Plain variable: {plainVar}</p>
      <p>State variable: {stateVar}</p>

      <button onClick={() => { plainVar++; }}>Increment Plain</button>
      <button onClick={() => setStateVar(stateVar + 1)}>Increment State</button>
    </div>
  );
}
Clicking Increment Plain won’t update the UI — because React doesn’t know the variable changed.
Clicking Increment State updates the UI — because React re-renders when state changes.

Virtual DOM(Explantion):
Actual DOM
The DOM is the browser’s live tree of nodes representing your HTML.

When you change something (like document.getElementById(...).textContent = "new text"), the browser updates the DOM and re-renders that part of the page.

Problem: Direct DOM updates are relatively slow if you do them often, especially in large apps, because the browser has to recalculate styles, layouts, and repaint.

🪞 Virtual DOM
The Virtual DOM is a lightweight copy of the real DOM that React keeps in memory.

When your component’s state changes:

React updates the Virtual DOM first.

React compares the new Virtual DOM with the previous one (this process is called diffing).

React finds the minimal set of changes needed.

React applies only those changes to the real DOM.

👉 This makes updates faster and more efficient, because React avoids touching parts of the DOM that didn’t change.

z-index controls the stacking order of elements on a web page.

Think of your page as having layers (like sheets of paper stacked on top of each other).

Elements with a higher z-index value appear in front of elements with a lower value.
